# Docker & GitHub Lab

A learning repository for Docker and GitHub practice.

## Current status

This repository currently contains this README only. Container examples, Dockerfiles, application code and GitHub Actions workflows have not yet been added.

## Inspect the current repository

```bash
git clone https://github.com/HaziqBinAfzal/docker-github-lab.git
cd docker-github-lab
git ls-files
git log --oneline
```

At this stage, `git ls-files` lists only `README.md`. There is no image to build or application to start.

## Planned learning exercises

- Build and run a small containerized application.
- Document image builds, port mappings and cleanup commands.
- Practice tracking changes through Git commits and GitHub pull requests.
- Add a reproducible workflow with verification steps and recorded results.

These are planned exercises, not completed implementations. Setup and run instructions will be added alongside the actual files.
